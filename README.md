## Featured Projects

**🏢 Tech Layoffs Analysis (2020–2023)**
End-to-end SQL cleaning and EDA on real, messy layoffs data — duplicate handling with no unique ID, text standardization, and a data-limitation finding around funding data and layoff severity.

**📦 E-Commerce Sales Validation**
Data quality validation and EDA on a large-scale (~100K row) sales dataset — culminating in the discovery that the dataset's unnaturally uniform patterns indicated synthetic origin, not genuine transaction data.

**🏥 Patient Outcomes Analysis**
Investigated relationships between cost, length of stay, readmission, and outcome in patient records — traced a surface-level cost/outcome correlation back to its true underlying cause (condition type) rather than accepting it at face value.

**🩺 Hospital Management System — Multi-Table SQL Analysis**
Full relational analysis across five linked tables (patients, doctors, appointments, treatments, billing) — chained joins, window functions, CTEs, and KPI development covering revenue, doctor workload, and department performance.
